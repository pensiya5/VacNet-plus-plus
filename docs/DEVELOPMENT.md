# Разработка VacNet++

Для сборки из исходников нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm run check
```

`check` проверяет TypeScript, собирает расширение для Chrome и Firefox и проверяет содержимое обеих сборок: разрешения, скрипты, ресурсы и переводы.

После добавления или удаления ключей в `public/_locales` выполните `npm run generate:i18n`, чтобы обновить типизированный список переводов.

| Команда | Результат |
| --- | --- |
| `npm run dev` | Разработка в Chrome с автоматической перезагрузкой |
| `npm run dev:firefox` | Разработка в Firefox |
| `npm run build:all` | Обе сборки в `.output/chrome-mv3` и `.output/firefox-mv3` |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run zip` | Архив для Chrome в `.output` |
| `npm run zip:firefox` | Архив для Firefox в `.output` |

Для ручной установки выбирайте папку соответствующей сборки, а не корень репозитория. Firefox-сборка использует отдельный локальный ID `vacnet-toolkit-local@extensions.invalid`; её настройки и история хранятся отдельно от опубликованного дополнения. При необходимости перенесите историю через экспорт и импорт. Локальный архив Firefox не подписан.

Для браузерных проверок установите тестовый Chromium и запустите сценарии. Они используют отдельный временный профиль и искусственную страницу портала, не отправляют настоящие вердикты:

```sh
npx playwright install chromium
npm run check:all
```

Если тестовый Chromium не запускается на Windows, можно использовать установленный Chrome через отдельный временный профиль:

```powershell
$env:VACNET_E2E_CHROME_EXECUTABLE = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
npm run check:all
```

Тестовый запуск включает отладочную загрузку расширения только в этом временном профиле. Личный профиль браузера не используется.

`npm run test:browser` запускает только браузерные сценарии после сборки. Публичная проверка GitHub включается отдельно переменной `VACNET_E2E_LIVE_UPDATES=1`. В CI установка браузера и проверки выполняются автоматически.
