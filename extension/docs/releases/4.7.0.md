# VacNet++ 4.7.0

## Что изменилось

- Английский интерфейс доступен вместе с русским. Добавлены испанский, немецкий, бразильский португальский и упрощённый китайский.
- Расширение выбирает предпочитаемый язык браузера. Если для него нет перевода, интерфейс открывается на английском.
- Локализация охватывает панель проверки, журнал, статистику, меню плеера и встроенный пример таймера.
- Обновлена зависимость Zod до версии 4.6.7. Браузерные тесты проверяют все шесть языков и возобновление воспроизведения после выбора вердикта.

## Установка

- Chrome, Edge, Brave и другие Chromium-браузеры — `vacnet-plus-plus-4.7.0-chrome.zip`.
- Firefox 128 и новее — `vacnet-plus-plus-4.7.0-firefox.zip` для временной установки через `about:debugging`.
- Контрольные суммы обоих архивов — `SHA256SUMS.txt`.

При обновлении замените файлы в прежней папке расширения, перезагрузите расширение и обновите вкладку VACNet.

## English summary

VacNet++ now supports English, Russian, Spanish, German, Brazilian Portuguese, and Simplified Chinese. It follows the browser’s preferred language and falls back to English. Localization covers the review interface, clip history, statistics, the player menu, and the built-in timer example. This release also updates Zod to 4.6.7 and adds browser coverage for all six languages.
