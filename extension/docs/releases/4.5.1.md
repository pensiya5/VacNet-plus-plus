# VacNet++ 4.5.1

**Исправляющий релиз / Attribution & packaging update**

## Что изменилось

- Добавлены явные ссылки на оригинальный проект [VACNET Toolkit Extension](https://github.com/MartinDawgor/VacNet-Toolkit-Extension) и его автора [MartinDawgor](https://github.com/MartinDawgor).
- Уточнено, что VacNet++ — неофициальная модификация, созданная и поддерживаемая отдельно от исходного проекта.
- Указан период модификаций: сентябрь–октябрь 2026 года; сохранена лицензия GNU GPL v3.0.
- В ZIP-сборки Chrome и Firefox включены `LICENSE` и `ATTRIBUTION.md`.
- Обновлена версия на 4.5.1. Новых функций по сравнению с 4.5.0 нет.
- Обновлён браузерный тест проверки версии: теперь он сверяется с установленным расширением.

## Скачать / Download

- **Chrome, Edge, Brave, Chromium:** `vacnet-plus-plus-4.5.1-chrome.zip`.
- **Firefox 128+:** `vacnet-plus-plus-4.5.1-firefox.zip` (unsigned, for temporary/manual loading).
- **Source code:** `Source code (zip)` or `Source code (tar.gz)` for this tag.
- **Checksums:** `SHA256SUMS.txt`.

Для установки распакуйте соответствующий ZIP и загрузите папку с `manifest.json` в браузере. При обновлении не удаляйте ранее установленное расширение, чтобы избежать потери локальных данных.

## English summary

VacNet++ v4.5.1 updates attribution and redistribution notices, includes the GPL-3.0 license and original-project attribution in both browser packages, and corrects version metadata. It is an unofficial modification of [MartinDawgor's VACNET Toolkit Extension](https://github.com/MartinDawgor/VacNet-Toolkit-Extension); the original author is not responsible for this fork. **No runtime features are changed from 4.5.0.**
