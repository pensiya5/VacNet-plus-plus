# VacNet++ 4.6.0

**Фичевый релиз / Plugin system & display updates**

## Что изменилось

- **Система плагинов «вставил и работает»**: пользовательский JavaScript исполняется в изолированной sandbox-странице MV3 (без доступа к расширению и странице), управление — во вкладке «Плагины» дашборда. Плагины можно создавать в редакторе, импортировать из `.js` файла и переключать тумблером.
- **API плагинов**: события (`clip-loaded`, `verdict-submitted`, `settings-changed`, `card-action` и другие), локальное хранилище, настройки плагина с UI, карточки двух слотов — «Метрики» и «под панелью вердикта» (с полосами вероятностей, этапами и кнопками), CSS-инъекция и сеть строго до localhost.
- **Вердикт нового формата в истории плагинов**: экспорт/журнал учитывают ответ «Читер/Не читер».
- **Экраны 2K и выше**: раскладка проверки растёт по высоте (видео больше не зажато в 1920px), шапка, футер и плавающий тулбар масштабируются ступенчато (FullHD не изменён); высота плеера ограничена вьюпортом — перемотка всегда в пределах экрана.
- **Welcome-страница**: приветственная карточка без псевдо-заголовка первой строки и лишнего разделителя.
- **Таймер (пример)**: усреднение времени сохраняется между сессиями.

## Скачать / Download

- **Chrome, Edge, Brave, Chromium:** `vacnet-plus-plus-4.6.0-chrome.zip`.
- **Firefox 128+:** `vacnet-plus-plus-4.6.0-firefox.zip` (unsigned, for temporary/manual loading).
- **Source code:** `Source code (zip)` or `Source code (tar.gz)` for this tag.
- **Checksums:** `SHA256SUMS.txt`.

Для установки распакуйте соответствующий ZIP и загрузите папку с `manifest.json` в браузере. При обновлении не удаляйте ранее установленное расширение, чтобы избежать потери локальных данных. Вкладка «Плагины» работает в Chromium-браузерах; Firefox не поддерживает sandbox-страницы MV3.

## English summary

VacNet++ v4.6.0 introduces a runtime plugin system: user JavaScript runs in an isolated MV3 sandbox with a validated API (events, storage, per-plugin settings, localhost-only network, cards in two slots including one under the verdict panel, file import). On 2K+ screens the review layout, header, footer and floating toolbar scale with the viewport, and the welcome card is cleaned up. The plugin tab is unavailable in Firefox (no MV3 sandbox support) and shows a notice there.
