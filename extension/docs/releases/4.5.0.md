# VacNet++ 4.5.0

Обновление журнала клипов, новая статистика и проверка обновлений. Проект теперь называется **VacNet++**, репозиторий — **VacNetPlusPlus**.

## Новые возможности

- **Поиск и фильтры журнала:** ID задания или видео, вердикт, точные повторы и диапазон дат. Фильтры можно сочетать и сбрасывать одной кнопкой.
- **Статистика:** отдельная панель по ссылке внизу страницы рядом с журналом и метриками. Показывает сохранённые проверки за сегодня, повторы и распределение ответов для обоих форматов проверки.
- **Время просмотра сессии:** учитывает фактическое воспроизведение без пауз, перемотки и загрузки. Сбрасывается при открытии страницы.
- **Проверка обновлений:** автоматический поиск стабильных релизов при открытии VACNet и ручная кнопка слева снизу. Переход к новой версии выполняется через страницу релиза; установка остаётся ручной.
- **Расширенные метрики:** тип и формат проверки, выбранный ответ, тик и время решения, доступность подтверждения и состояние отправки.
- **Новый README:** описание возможностей, галерея скриншотов и инструкции по установке на русском и английском.

## Исправления

- Исправлен браузерный запрос обновлений, который мог завершаться ошибкой `Illegal invocation`.
- Улучшена миграция истории: проверка данных до сохранения, последовательная запись и защита от потери записей при запуске.
- Горячие клавиши не управляют клипом во время работы в панели, диалоге или поле ввода.
- Добавлены автоматические сценарии для собранного расширения в настоящем браузере: обновления, возобновление видео после вердикта, переход между заданиями, журнал и статистика.

## Скачать и установить

- **Chrome, Edge, Brave и Chromium:** `vacnet-plus-plus-4.5.0-chrome.zip`.
- **Firefox 128+:** `vacnet-plus-plus-4.5.0-firefox.zip`. Архив не подписан; временная установка через `about:debugging`.
- **Исходники:** стандартные архивы Source code на странице релиза соответствуют тегу `v4.5.0`.

Для Chromium распакуйте архив, включите режим разработчика на странице расширений и загрузите папку с `manifest.json`.

При обновлении замените файлы в прежней папке и перезагрузите расширение. Перед обновлением можно экспортировать историю в JSON. Не удаляйте установленное расширение, если хотите сохранить его локальные данные.

Статистика использует сохранённый журнал, а не общее число проверок аккаунта. В новом формате запись появляется после перехода к следующему заданию в той же вкладке.
