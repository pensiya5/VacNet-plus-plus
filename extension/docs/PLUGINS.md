# Плагины VacNet++

VacNet++ поддерживает небольшие пользовательские плагины на JavaScript: вставили код в редакторе — плагин сразу выполняется, без пересборки расширения. Механика похожа на Tampermonkey, только код живёт внутри VacNet++ и получает его API.

Открыть управление плагинами: нижние ссылки на странице проверки → **Плагины**.

## Как это работает

- Код плагина выполняется в **изолированной песочнице** (sandbox-страница Manifest V3). У песочницы нет доступа к расширению, странице портала и сети — только к API `vacnet`, которое предоставляет VacNet++.
- Каждое действие плагина валидируется на хосте. Вердикты можно отправлять только через официальный пайплайн расширения — проверки портала не обходятся.
- Плагин, который выбрасывает ошибку, помечается как ошибочный и не ломает остальные плагины.
- Данные плагина хранятся локально в браузере (`browser.storage.local`), отдельно для каждого плагина. Телеметрии нет.
- Ограничения: до **20** плагинов, код до **256 КБ**, данные плагина до **64 КБ** на значение.
- Плагины работают в Chrome, Edge и других Chromium-браузерах. Firefox не поддерживает sandbox-страницы Manifest V3 — в нём вкладка «Плагины» покажет предупреждение.

## Быстрый старт

1. Откройте дашборд → **Плагины** → **Вставить пример**.
2. Нажмите **Сохранить и применить**.
3. Плагин «Таймер проверки» включён: карточка появляется в разделе **Метрики** — время на текущем клипе и среднее время по всем сохранённым вердиктам (считается между сессиями).

Тот же код лежит отдельным файлом: [`docs/examples/review-timer.js`](./examples/review-timer.js) — можно вставить в редактор плагина вручную или поделиться файлом. Сборка проверяет, что файл и встроенный пример не расходятся.

Кнопки в списке плагина:

| Действие | Что делает |
| --- | --- |
| Переключатель | Включить/выключить плагин (код сохраняется) |
| Изменить | Открыть редактор; **Сохранить и применить** перезапускает плагин без перезагрузки страницы |
| Удалить | Дважды нажмите для подтверждения; данные плагина тоже удаляются |

## API

Тело плагина — обычный JavaScript. Он выполняется сразу с единственным аргументом `vacnet`. Если плагин возвращает функцию, она вызывается при выключении или замене плагина (удобно останавливать таймеры и слушателей).

```js
const timer = setInterval(() => { /* ... */ }, 1000);

vacnet.on('clip-loaded', (event) => {
  vacnet.log('Новый клип', event.clip.taskId);
});

// очистка при выключении плагина
return () => clearInterval(timer);
```

### `vacnet.plugin` — сведения о плагине

`{ id, name, version }` — как указано в редакторе.

### `vacnet.on(name, handler)` — события

Подписка на события проверки. Возвращает функцию отписки.

| Событие | Аргумент |
| --- | --- |
| `clip-loaded` | `{ clip, deduplication }` — новый клип открыт. `clip`: `{ taskId, sourceWebmUrl, videoId, range: {start,end}, eventTime, reviewType, clipCount, app, matchTimestamp, webmDuration }`; `deduplication`: `'new-match' \| 'new-clip' \| 'exact-duplicate' \| null` |
| `snapshot-changed` | `{ snapshot }` — любое изменение состояния проверки (клип, вердикты, отправка, ошибка) |
| `verdict-submitted` | `{ clip, verdicts, badClip }` — вердикт сохранён в журнал |
| `history-changed` | `{ entryCount, repeats }` — журнал изменился |
| `preferences-changed` | `{ preferences }` — изменились настройки VacNet++ |

### `vacnet.storage` — данные плагина

- `get()` → `Promise<Record<string, unknown>>` — все данные плагина.
- `set(key, value)` — сохраняет значение (JSON-сериализуемое, до 64 КБ).
- `remove(key)` — удаляет ключ.

### `vacnet.settings` — настройки плагина

Плагин может объявить настройки — они появятся во вкладке «Плагины» под карточкой, а их значения сохраняются между сессиями.

```js
// Объяви настройки в теле плагина (вызывается один раз при загрузке):
vacnet.settings.define([
  { key: 'auto', type: 'toggle', label: 'Автозапуск', default: false },
  { key: 'model', type: 'choice', label: 'Модель', default: 'videomae_v5d_cascade_full',
    options: ['videomae_v5d_cascade_full', 'mvit_v1'] },
  { key: 'port', type: 'number', label: 'Порт', default: 8770, min: 1024, max: 65535 },
  { key: 'name', type: 'text', label: 'Подпись', default: '' },
]);

// Текущие значения (сохранённые или default):
const values = await vacnet.settings.get();

// Изменение настроек пользователем приходит событием:
vacnet.on('settings-changed', (event) => {
  if (event.pluginId !== vacnet.plugin.id) return; // событие общее для всех плагинов
  console.log('новые настройки', event.values);
});
```

Типы: `toggle` (чекбокс), `choice` (список, требует `options`), `number` (с `min`/`max`), `text`. До 12 настроек на плагин; ключи — строчные латинские буквы, цифры, точка, дефис, подчёркивание.

### `vacnet.net.fetch` — запросы к локальным службам

```js
const response = await vacnet.net.fetch('http://127.0.0.1:8770/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ hello: 'world' }),
  timeoutMs: 120000,
});
const data = JSON.parse(response.text); // {status, ok, text}
```

- Разрешены **только loopback-адреса**: `127.0.0.1`, `localhost`, `[::1]` — плагин не может отправить данные наружу.
- Таймаут настраивается (`timeoutMs`, 1–300 с, по умолчанию 120 с — локальный инференс может быть долгим).
- Ответ больше 2 МБ обрезается. Локальная служба должна отдавать CORS-заголовок `Access-Control-Allow-Origin: *`.
- Запросы к внешним сайтам (включая портал Valve) запрещены — URL клипов не покидают твой компьютер.

Данные живут между сессиями и удаляются вместе с плагином.

### `vacnet.ui.setCard(card)` / `clearCard(slot)` — карточки плагина

`card = { title, text, slot?, bars?, actions?, progress? }`. По умолчанию карточка появляется вверху раздела **Метрики**; со `slot: 'review'` — под панелью вердикта прямо на странице проверки (оформлена как панель вердикта). Текст поддерживает переносы строк. `clearCard('metrics' | 'review')` убирает карточку из указанного слота.

Дополнительные поля:

```js
vacnet.ui.setCard({
  title: 'ИИ-рекомендация',
  text: 'Похоже на wallhack — проверь этот признак.',
  slot: 'review',
  bars: [                                    // полосы вероятностей (до 8)
    { label: 'aimassist', value: 0.29 },     // value: 0..1
    { label: 'wallhack', value: 0.73 },
  ],
  progress: { value: 0.4, label: 'Скачиваю клип: 12 МБ' },  // тонкая полоса этапов
  actions: [{ key: 'analyze', label: 'Перепроверить' }],    // кнопки (до 3)
});
```

Клик по кнопке карточки приходит событием:

```js
vacnet.on('card-action', (event) => {
  if (event.pluginId !== vacnet.plugin.id) return;
  if (event.key === 'analyze') startAnalysis();
});
```

### Готовый пример: ИИ-рекомендации

[`docs/examples/ai-recommendations.js`](./examples/ai-recommendations.js) — плагин, который отправляет клип в твою локальную службу анализа и показывает рекомендации под панелью вердикта: этапы выполнения (скачивание → кадры → нейросеть), полосы вероятностей по категориям и кнопку запуска. Настройки плагина — автозапуск, модель, порт службы, число окон для усреднения.

Служба слушает только `127.0.0.1` и принимает только клипы с CDN Valve (`replay-video.valve.net`); сам анализ выполняется твоим оборудованием, данные не покидают компьютер.

### `vacnet.dom.addCss(css)` — стили страницы проверки

Добавляет CSS к странице портала от имени плагина. Передайте `null` (`vacnet.dom.addCss(null)`), чтобы убрать свой стиль. CSS удаляется автоматически при выключении плагина. Селекторы применяются только к оформлению — клики и отправка форм остаются за штатным интерфейсом.

### `vacnet.emitReviewCommand(command)` — вердикты

Отправляет команду проверки через штатный интерфейс. Доступны те же команды, что и у кнопок/горячих клавиш:

```js
// выбрать ответы и отправить (как кнопка «Отправить»)
await vacnet.emitReviewCommand({ type: 'set-verdicts', verdicts: { aimassist: 'skip', wallhack: 'skip', autobhop: 'skip', bot: 'skip', cheating: 'positive' } });
await vacnet.emitReviewCommand({ type: 'submit', verdicts: { aimassist: 'skip', wallhack: 'skip', autobhop: 'skip', bot: 'skip', cheating: 'positive' }, badClip: false });

// подтверждение в новом формате проверки
await vacnet.emitReviewCommand({ type: 'confirm-verdict' });
```

Расширение не отправит команду, если портал не позволяет отправку; проверка доступности остаётся на стороне VacNet++.

### `vacnet.emitPlayerCommand(command)` — плеер

`toggle-playback`, `restart`, `toggle-zoom`, `jump-to-event`, `change-speed` (`{ direction: -1 | 1 }`), `step` (`{ direction: -1 | 1 }`).

### `vacnet.log(...)` — журнал

Пишет в консоль страницы с префиксом `[vacnet-plugin:<id>]` (виден в DevTools вкладки).

## Ограничения и безопасность

- Плагины не имеют доступа к `fetch` чужих доменов через API расширения, к `chrome.*`, к странице портала напрямую и к данным других плагинов.
- Не вставляйте код из недоверенных источников: плагин выполняется в песочнице, но может отправлять вердикты от вашего имени и менять оформление страницы. Чужой плагин, предлагающий «авто-вердикты», может отправлять ответы без вашего участия — решение всегда за вами.
- Гостевые ссылки и ссылки приглашений содержат параметры доступа — не передавайте их плагинам и не логируйте.
