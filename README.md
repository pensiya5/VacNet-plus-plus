## Возможности 4.5.0

- **Единый дизайн:** графитовые поверхности, ледяной синий акцент и мягкое свечение на страницах проверки, приветствия и приглашений.
- **Проверка клипов:** один общий вопрос в новом режиме или четыре независимые категории в старом. Ответы занимают всю ширину панели, а выделение плавно перемещается между ними.
- **Журнал клипов:** поиск по ID задания или видео, фильтры по вердикту, повторам и датам, импорт и экспорт истории.
- **Статистика:** сохранённые проверки за сегодня, распределение ответов и время фактического воспроизведения за текущую сессию. Открывается по ссылке внизу страницы рядом с журналом и метриками.
- **Обновления:** автоматическая и ручная проверка релизов VacNet++ через кнопку в левом нижнем углу.

Плеер Plyr сохраняет привычное управление. После выбора вердикта видео останавливается, и его можно снова включить для повторного просмотра.

## 🚀 Быстрый старт

> Нужен действующий доступ к официальному порталу разметки VACNet.

1. Скачайте архив для своего браузера на странице [Releases](https://github.com/pensiya5/VacNetPlusPlus/releases).
2. Распакуйте архив в отдельную папку.
3. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите распакованную папку и откройте портал VACNet.

**Обновление установленной версии:** замените файлы в той же папке расширения и нажмите значок перезагрузки на его карточке в `chrome://extensions`. Используйте прежнюю папку, чтобы сохранить настройки и локальную историю; перед обновлением можно экспортировать историю в JSON.

<details>
<summary><b>Установка в Firefox</b></summary>

3. Нажмите **Загрузить временное дополнение** и выберите `manifest.json` из распакованной сборки.

Временное дополнение потребуется загрузить повторно после перезапуска Firefox. Для постоянной установки нужен подписанный пакет.

## Разработка

Для сборки из исходников нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm run check
```

`check` проверяет TypeScript, собирает расширение для Chrome и Firefox и проверяет содержимое обеих сборок: разрешения, скрипты, ресурсы и переводы.

После добавления или удаления ключей в `public/_locales` выполните `npm run generate:i18n`, чтобы обновить типизированный список переводов.

| Команда | Результат |
| --- | --- |
| `npm run dev` | Разработка в Chrome с автоматической перезагрузкой |
| `npm run dev:firefox` | Разработка в Firefox |
| `npm run build:all` | Обе сборки в `.output/chrome-mv3` и `.output/firefox-mv3` |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run zip` | Архив для Chrome в `.output` |
| `npm run zip:firefox` | Архив для Firefox в `.output` |

Для ручной установки выбирайте папку соответствующей сборки, а не корень репозитория. Firefox-сборка использует отдельный локальный ID `vacnet-toolkit-local@extensions.invalid`; её настройки и история хранятся отдельно от опубликованного дополнения. При необходимости перенесите историю через экспорт и импорт. Локальный архив Firefox не подписан.

Для браузерных проверок установите тестовый Chromium и запустите сценарии. Они используют отдельный временный профиль и искусственную страницу портала, не отправляют настоящие вердикты:

```sh
npx playwright install chromium
npm run check:all
```

Если тестовый Chromium не запускается на Windows, можно использовать установленный Chrome через отдельный временный профиль:

```powershell
$env:VACNET_E2E_CHROME_EXECUTABLE = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
npm run check:all
```

Тестовый запуск включает отладочную загрузку расширения только в этом временном профиле. Личный профиль браузера не используется.

`npm run test:browser` запускает только браузерные сценарии после сборки. Публичная проверка GitHub включается отдельно переменной `VACNET_E2E_LIVE_UPDATES=1`. В CI установка браузера и проверки выполняются автоматически.

## Что нового в 4.5.0

- Новое название: **VacNet++**, репозиторий **VacNetPlusPlus**.
- Поиск журнала по ID задания или видео, фильтры по вердикту, повтору и диапазону дат.
- Нижняя ссылка **Статистика** открывает отдельную панель с сохранёнными проверками за сегодня и распределением ответов.
- Время просмотра текущей сессии считает фактическое воспроизведение, исключая паузы, перемотку и загрузку. Сессия начинается при открытии страницы.
- Автоматические браузерные сценарии проверяют собранное расширение: обновления, проигрывание после выбора ответа, переход между заданиями, журнал и статистику.
- Исправлен вызов браузерного запроса обновлений; кнопка находится в левом нижнем углу.

## Что нового в 4.2.1

- Исправлено повторное выключение видео примерно через 250 мс после возобновления просмотра с выбранным вердиктом.
- Журнал демок и метрики разработчика теперь совпадают по размеру с правой панелью на разных экранах.

## Интерфейс и инструменты

Тема Graphite & Ice приводит интерфейс портала к единому виду: тёмные графитовые поверхности, холодный синий акцент и мягкая подсветка доступных действий. Обновлены панель проверки, история, пресеты, метрики и страницы приветствия с приглашениями. Плеер Plyr и его управление остались прежними.

### Два формата проверки

| Режим клипа | Как выбирается ответ |
| --- | --- |
| Новый клип | Один вопрос: **Читер**, **Неясно** или **Не читер**. Ответ можно сменить до подтверждения; отправка выполняется через штатные элементы сайта. |
| Старый клип | Четыре независимые категории: **Aim Assist**, **Wall Hack**, **Auto BHop** и **Bot**. В каждой — **Да**, **Не уверен** или **Нет**. Все три ответа растянуты по ширине панели. |

Активный вариант плавно перемещается между кнопками и получает цвет выбранного ответа. При включённом в системе сокращении движения переход становится мгновенным. Лишние кнопки отмены и пропуска убраны из панели проверки.

### Инструменты для разбора записи

- **Плеер Plyr:** скорость от 0,25× до 4×, покадровый переход, увеличение 2×, настройка громкости и отметка подозрительного момента, если сайт её передал.
- **Пресеты:** до девяти быстрых наборов вердиктов. Их можно вызывать клавишами 1–9; мгновенная отправка задаётся отдельно для каждого набора.
- **История:** до 1000 заданий, сгруппированных по матчу. Поиск и фильтры помогают найти прошлые ответы и повторы; историю можно импортировать и экспортировать в JSON. В новом режиме общий ответ и `verdict_tick` сохраняются после открытия следующего задания в той же вкладке. До перехода запись хранится временно 10 минут; без следующего задания она ещё не попадает в журнал.
- **Статистика:** число сохранённых проверок за текущий день и распределение ответов отдельно для двух форматов проверки. Сессионный счётчик учитывает воспроизведение без пауз, перемотки и загрузки и начинается заново при открытии страницы.
- **Обновления:** проверка новых стабильных релизов VacNet++ при открытии VACNET, не чаще раза в сутки. В левом нижнем углу — кнопка ручной проверки и ссылка на новый релиз. Повторные ручные запросы ограничены одной минутой; установка обновления выполняется вручную.
- **Метрики:** сведения о клипе и плеере, тип и формат проверки, этап и состояние отправки. Для нового режима также показаны выбранный ответ, тик и время решения, доступность ответов и подтверждения.
- **Переводы:** интерфейс сейчас использует русский язык; в исходниках поддерживаются каталоги RU и EN.

## Управление

| Клавиша | Действие |
| --- | --- |
| 1–9 | Выбрать соответствующий пресет |
| Пробел | Воспроизвести или приостановить видео |
| R | Вернуться к началу клипа |
| ← / → | Перейти на кадр назад или вперёд |
| [ / ] | Уменьшить или увеличить скорость |
| Z | Включить или выключить масштаб 2× |
| E | Перейти к отмеченному событию, если оно есть |
| Enter | Отправить ответ или подтвердить его, когда это разрешено сайтом |
| Esc | Закрыть открытую панель |

Горячие клавиши не срабатывают во время ввода текста, при работе с кнопками и полями, в открытом диалоге или во время отправки. Цифровой пресет с включённой мгновенной отправкой сразу передаёт сохранённые ответы.

## Данные и приватность

- Настройки, пресеты и история хранятся в локальном хранилище браузера.
- Расширение не содержит аналитики и телеметрии и не отправляет данные разработчику.
- Сетевые запросы используются порталом для отправки выбранного вердикта, загрузки задания, чтения его данных и воспроизведения видео Valve.
- Проверка обновлений обращается к API GitHub (`api.github.com`) за последним публичным релизом VacNet++. История, вердикты и данные клипов в этот запрос не входят.
- Буфер обмена используется только после явного нажатия кнопки копирования.

Экспорт истории и гостевые ссылки могут содержать адреса с параметрами доступа. Не публикуйте их вместе с отчётами или снимками экрана.

## Важно

VacNet++ помогает просматривать записи и передавать выбранные человеком ответы. Расширение не определяет наличие читов самостоятельно. Пользуйтесь порталом по его правилам и не распространяйте материалы проверок.
