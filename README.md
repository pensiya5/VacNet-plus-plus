## Возможности

| | Что умеет VacNet++ |
| :--- | :--- |
| **🎬 Плеер Plyr** | Скорость 0,25–4×, покадровый переход, увеличение 2× и управление с клавиатуры. После выбора вердикта просмотр можно возобновить. |
| **🎯 Два формата проверки** | Один вопрос «Читер / Неясно / Не читер» в новых клипах и четыре категории в старых: Aim Assist, Wall Hack, Auto BHop и Bot. |
| **⚡ Пресеты вердиктов** | До девяти сохранённых наборов ответов, вызов клавишами 1–9 и отдельная настройка мгновенной отправки для каждого набора. |
| **📚 Журнал клипов** | До 1000 заданий с группировкой по матчу. Поиск по ID задания или видео, фильтры по вердикту, повторам и датам. Импорт и экспорт в JSON. |
| **📊 Статистика** | Сохранённые проверки за сегодня, распределение ответов и время просмотра текущей сессии без пауз, перемотки и загрузки. |
| **🔎 Метрики разработчика** | Данные клипа и плеера, формат проверки, состояние отправки, выбранный ответ, тик и время решения. |
| **🔄 Проверка обновлений** | Автоматическая проверка стабильных релизов и кнопка слева снизу для ручной проверки. Установка новой версии — вручную. |
| **🌙 Единое оформление** | Тёмная тема для проверки, пресетов, журнала, метрик, приветствия и приглашений. Плавное выделение ответа и поддержка сокращения движения. |

**Журнал, метрики и статистика открываются по ссылкам внизу страницы.** Их панели используют единое оформление и адаптируются к размеру окна.

## Установка

> Для работы нужен действующий доступ к официальному порталу VACNet. Расширение не выдаёт доступ к проверкам.

### Chrome, Edge, Brave и другие Chromium-браузеры

1. Откройте [последний релиз](https://github.com/pensiya5/vacnet-plus-plus/releases/latest) и скачайте архив с окончанием **`-chrome.zip`**.
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, внутри которой находится `manifest.json`.
5. Откройте или перезагрузите страницу VACNet.

<details>
<summary><b>Firefox 128 и новее</b></summary>

Скачайте архив **`-firefox.zip`**, распакуйте его и откройте `about:debugging#/runtime/this-firefox`. Нажмите **Загрузить временное дополнение** и выберите `manifest.json`.

Временную установку нужно повторять после перезапуска браузера. Для постоянной установки требуется подписанный пакет. Локальная сборка использует отдельный ID; историю из другого дополнения можно перенести через экспорт и импорт.

</details>

**Как обновить:** замените файлы в прежней папке расширения, нажмите значок перезагрузки на его карточке и обновите страницу VACNet. Сохраняйте ту же папку; перед обновлением можно экспортировать историю.

## Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| **Пробел** | Воспроизведение / пауза |
| **← / →** | Кадр назад / вперёд |
| **[ / ]** | Уменьшить / увеличить скорость |
| **R** | Вернуться к началу |
| **Z** | Включить / выключить увеличение 2× |
| **E** | Перейти к отмеченному событию, если оно доступно |
| **1–9** | Применить сохранённый пресет |
| **Enter** | Отправить или подтвердить ответ, когда действие доступно |
| **Esc** | Закрыть открытую панель |

Во время ввода текста и работы в диалогах клавиши не управляют записью под ними. Пресет с включённой мгновенной отправкой сразу отправляет сохранённый ответ.

## Полезно знать

- **История нового формата** сохраняется при переходе к следующему заданию в той же вкладке. До перехода запись ожидает сохранения до 10 минут.
- **Статистика за день** считается по сохранённым записям журнала, а не по всем проверкам аккаунта. Время сессии сбрасывается при открытии страницы.
- **Данные остаются в браузере:** настройки, пресеты и история хранятся локально. Аналитики и телеметрии нет. Проверка обновлений обращается к GitHub без передачи истории и вердиктов.
- **Экспорт и гостевые ссылки** могут содержать параметры доступа. Не публикуйте их в отчётах или на скриншотах.
